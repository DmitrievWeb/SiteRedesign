# Dala — Style Reference (рабочая выжимка)
> Constellation floating on black velvet. Theme: dark.

## Цвета
--void:#000000 (канвас — чистый чёрный, не тёмно-серый!) · --white:#ffffff (единственный цвет текста) ·
--ash:#9a9a9a (вторичный) · --silver:#bdbdbd (третичный) ·
--iris:#8052ff (ЕДИНСТВЕННАЯ заливка кнопок + бренд) · --saffron:#ffb829 (акцент-подсветка текста/ссылок) ·
--verdant:#15846e (только градиент логотипа).

## Типографика (PPNeueMontreal → Inter)
- Все заголовки вес 400 (НИКОГДА не bold) — иерархия через МАСШТАБ: 78–113px, tracking -0.04em.
- Body 18px вес 200 (ультралайт — сигнатура системы, не подменять на 400).
- Нав/лейблы: 14px вес 600 UPPERCASE tracking .025em.

## Формы
Радиусы: кнопки/нав/карточки 24px, теги 9999px. Карточек-контейнеров НЕТ:
элементы плавают на чёрном, разделение только воздухом. Теней нет. Градиентов на UI нет.

## Сигнатура
Поле из тысяч мелких цветных ТРЕУГОЛЬНИКОВ-частиц (контур 1–2px: фиолет/янтарь/тил/маджента),
образующих органическую форму (мозг/облако) — единственная hero-графика; фото запрещено в hero.
Ambient-частицы на малой прозрачности рассыпаны по фону.

## Layout
Двухколоночный асимметричный ритм: огромный левый заголовок + воздушное body. Максимум 1280px.
Секции 60–120px. Один violet-pill CTA на вью, остальные ссылки ghost.

## Don't
Violet как фон секций; body вес 400; карточки с рамками/тенями; несколько filled-кнопок рядом.
