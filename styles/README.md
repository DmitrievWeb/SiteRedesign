# Библиотека design.md — стилевые системы для демо

Формат: как на designmd.app / styles.refero.design — токены цветов, типографика,
компоненты, do/don't. Перед созданием нового демо выбрать подходящую систему
и следовать её правилам ТОЧНО (палитра, радиусы, веса шрифтов, запреты).

## Системы в библиотеке

| Файл | Суть | Кому подходит |
|---|---|---|
| sequel.md | Кинотеатр после полуночи: чистый #000, крем #f5f5f0 как единственный акцент, вес 300 в заголовках, италик-сериф для одного слова-эмоции, glass-бейджи | люкс-мебель, детейлинг, частные врачи, ателье |
| apple.md | Собор из белого: #fff/#f5f5f7 полосы, огромные заголовки 700, единственный синий #0071e3 только на CTA-pill, радиус карточек 28px, ноль теней | клиники, техника, «чистые» бренды |
| dala.md | Созвездие на чёрном бархате: #000 + фиолет #8052ff + янтарь #ffb829, вес 400 на 78–113px, частицы-треугольники, никаких карточек | ИИ/технологичные услуги, стартапы |
| aurora.md | Северное сияние: mesh-градиенты #0080FF/#FF1493/#00FFFF, медленные 8–12s анимации, сплит-hero, зигзаг-секции | креативные студии, премиум-SaaS |

## Главные правила применения (общие)

- Следовать секции Do/Don't системы буквально — она важнее вкуса.
- Один акцентный цвет на кнопках, и только он.
- Иерархия через масштаб и трекинг, а не через жирность (кроме Apple).
- Шрифты-заменители: PPNeueMontreal/VisueltPro/SF Pro → Inter; Bradford → Playfair Display italic.
- Кириллица обязательна: Inter, Playfair Display — ок.
